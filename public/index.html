Физическая модель и ограничения

Температурная оценка учитывает движение относительно средней скорости камеры: T* = Σ[(vx − v̄x)² + (vy − v̄y)²] / (2N). Давление оценивается как P* = N × T* для камер одинаковой площади.

Это наглядные относительные показатели, а не полноценное измерение механического давления в неравновесном газе. Температура пустой камеры не определена. Без столкновений между частицами модель не описывает полноценную термализацию.

Односторонний проход искусственно задан правилом программы. Реальный демон должен учитывать стоимость измерений, обработки информации, управления проходом и сброса памяти.
